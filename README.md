# Neowise. AI-помощник для входящих заявок

Нужен Node.js 20+. Зависимостей и ключей нет.

## Запуск

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно задать через `PORT`.

## Тесты

```sh
node --test triage.test.mjs
```

Имитатор модели принимает обычный текст. Метки `[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]` включают сценарии сбоя.
